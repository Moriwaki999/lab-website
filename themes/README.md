# 日替わりテーマ

`index.html` は、日本時間の日付に合わせて `themes/YYYY-MM-DD.css` を読み込みます。日付が変わる0時に、表示されるテーマも切り替わります。その日のファイルが無い日は `themes/fallback.css` を使います。

テーマのファイルは、毎晩の自動タスクが翌日分を1つ作り、`main` に push します。

## テーマを作るときのルール

- **変えてよいファイル**：`themes/YYYY-MM-DD.css`（新規）、`themes/fallback.css`（新しいテーマのコピー）、`themes/HISTORY.md`（1行追加）だけです。`index.html` などのHTML・文章・JavaScript は変えません。
- **同じものを繰り返さない**：`HISTORY.md` の過去のテーマと、配色・フォント・飾りの組み合わせが重ならないようにします。同じキーワードの回でも、前の回とは違う発想にします。
- **CSSの書き方**：`index.html` の基本スタイルを上書きする形で書きます。Google Fonts を使うときは、ファイルの先頭で `@import` します。画像は使わず、CSSのグラデーション・模様、インラインSVG（data URI）、文字・絵文字で表現します。既存のキャラクターやブランドの見た目はまねしません。
- **崩さない**：
  - 文字と背景のコントラストは 4.5:1 以上にして、本文をしっかり読めるようにします。
  - 幅375pxのスマホ表示で、横スクロールが出ないようにします。
  - 固定メニュー（`nav`、高さ60px）の高さと位置は変えません。
  - 表示の切り替えに使っているルールは上書きしません：`.cohort-panel` と `.cohort-panel.active`、`.news-item.news-hidden`、ツールチップの表示・非表示、`#totop` と `#totop.visible`。
- **確認**：Playwright でパソコン幅（1280px）とスマホ幅（375px）のスクリーンショットを撮り、画像を見て、崩れや読みにくさが無いことを確かめてから push します。
